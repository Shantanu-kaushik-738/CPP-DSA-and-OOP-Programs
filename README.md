# C++ DSA and OOP Programs

This repository contains my practice programs in C++ focusing on **Data Structures and Algorithms (DSA)** and **Object-Oriented Programming (OOP)** concepts.  
It is designed as a learning resource to strengthen problem-solving and programming skills.

---

## Topics Covered
- **Basic Math & Arrays**
  - `basic_maths` → Prime number  
  - `array` → Pascal's triangle  
  - `recursion` → Subsets of an array (TC: O(2^n * n))  

- **Searching & Sorting**
  - `binary_search` → Square root of a number  
  - `sorting` → LowerBound function for vector search  

- **Data Structures**
  - `linked_list` → Doubly linked list  
  - `stack_&_queue` → Queue using linked list  
  - `heap` → Kth smallest element in the array  
  - `binary_trees` → Tree traversal  

- **Bit Manipulation**
  - `bit_manipulation` → Toggle the ith bit of a number  

- **Strings**
  - `strings` → String operations in C++  

- **Patterns**
  - `patterns` → Butterfly pattern  

- **OOP Concepts**
  - `OOPS` → Object-Oriented Programming in C++  
  - `Object oriented program in cpp` → Core OOP examples  
  - `STL` → Standard Template Library usage
